# Layout Studio
Reusable dnd-kit sortable primitive for React pages. Home edit mode and Settings dashboard/Insights ordering use the same persisted order. Drag only from handles (touch-action none), keyboard supported, normal scrolling preserved outside handles. Hidden widgets retain their slots. Future surfaces: navigation, Astro, Acervo, diary panels, global edit state, resize and per-breakpoint layouts. Existing settings remain authoritative. Lockfile generated by PR repair workflow.
