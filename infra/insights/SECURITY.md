# Insights runtime security

The runtime group is NOLOGIN and NOBYPASSRLS. A separate non-owner login must be provisioned and explicitly assume this group. The trusted API must authenticate the owner and set `SELECT set_config('jardim.owner_id', $1, true)` inside each transaction, never from an untrusted request field. No direct browser SQL access. Missing owner fails closed. Catalog is read-only for runtime; ingestion needs a separate restricted role. Do not grant migration ownership to runtime. RLS protects against missing query filters, not a compromised trusted API that can set arbitrary owner IDs. Before binding Hyperdrive, verify cross-owner reads/writes with the actual login and transaction pooling. Preview databases must be empty or synthetic. Private context remains opt-in. Migration 0002 is one-time, transactional; track applied versions before automating.
