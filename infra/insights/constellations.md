# Contextual neighborhoods
Track-level distributions; deduplicate event IDs and exclude references. Compare shared dimensions using sum of minimum normalized category probabilities, equally weighted. Require five known observations per track per dimension, two shared dimensions and mean overlap >= 0.65. Return eight nearest neighbors per selected anchor; no global clustering, audio similarity or inference of causality. Local-only, inherits contextual opt-in. Sparse observations and common baseline contexts may inflate similarity. Complexity is linear in events plus comparisons against the selected anchor.
