# Sophia v1

Authenticated plan endpoint shares Oracle daily quota. Explicit consent sends question only to Workers AI; no history, location or mood records sent automatically. Strict allowlisted JSON schema on server and client; user confirms plan before local execution. No SQL, tool execution, generated factual answer or persistence. Supports conjunctions of explicit filters, ranking tracks or artist credits. Unknown context excluded and counted. Slow music threshold 90 BPM is provisional. Solar, relative dates, negation, comparisons and memory queries unsupported. Model can misinterpret questions; review plan. No Neon changes.
